# Paper Trade: SPY 760 Put — 2026-08-24

Paper-trading experiment only. No live order is placed.

## Objective
- Starting paper capital: $300
- Entry date: 2026-08-24
- Mandatory exit date: 2026-08-25
- Aggressive stretch target: grow the paper account to $1,200 total value (+300% return on the starting $300)
- Maximum defined loss: premium paid, capped below the $300 budget

## Simulated Position
- Underlying: SPY
- Contract: SPY 2026-08-25 760 Put
- Quantity: 5 contracts
- Simulated entry premium: $0.59 per share
- Cost per contract: $59
- Total simulated debit: $295
- Cash remaining: $5
- Maximum loss: $295

## Profit Math
To turn the $300 paper account into $1,200 by exit, the five contracts plus remaining cash must be worth $1,200.

Required option value = ($1,200 - $5) / 500 = $2.39 per share.

So the stretch target is approximately:
- Option target: $2.39+
- Position value: $1,195+
- Account value: $1,200+
- Account return: +300%

This is an intentionally high-risk, low-probability target and is not presented as an expected return.

## Exit Rules
1. Paper-only; never route this record to a live broker.
2. Hard exit all contracts on 2026-08-25 before expiration regardless of P/L.
3. If option premium trades at or above $2.39 before the forced exit, record the 300% account target as achieved and close the paper position.
4. If the option value collapses materially, loss remains capped at the $295 simulated premium.
5. Do not add capital, average down, roll, or increase quantity after entry.

## Thesis
This setup uses very short-dated SPY downside convexity because a $300 account cannot mathematically target a 300% one-day return with ordinary stock exposure. The trade requires a sharp enough downside move and/or volatility expansion for the put premium to multiply quickly. The same leverage that creates upside also creates a substantial chance of losing most or all of the premium.
